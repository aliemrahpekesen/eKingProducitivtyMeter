## Problem statement

The monorepo scaffold builds locally but nothing enforces the [QualityGatePolicy](../../engineering-operating-system/QualityGatePolicy.md) merge gates. Wire the CI pipeline so that from this PR forward every change passes G1 (build + static + Modulith/ArchUnit), G2 (tests + coverage ratchet), and the G3 automated portion (secret/dependency scan) before it can reach `main`, and record the branch-protection ruleset that makes the checks mandatory.

## Change class

CC-7 (build/infra tooling). No contract anchor, no schema, no security-relevant application surface. Pipeline secrets handling is R-SA co-owned but this task adds no secrets (public actions + gitleaks only).

## Acceptance criteria

1. CI runs **Static + Unit + Integration + Modulith/ArchUnit** stages on every PR and is green on the empty modules.
2. A PR that fails Spotless/Checkstyle is **blocked** at the Static stage (block-then-pass demonstrated).
3. Coverage ratchet is active (thresholds per [TestingStrategy §1](../../docs/testing/TestingStrategy.md): ≥85% eip-core, ≥75% elsewhere) and configured to fail below threshold.
4. `main` is protected: no direct push; PR + all required checks + one R-CR approval required (recorded as config-as-code; application requires a push — see deviations).

## Test plan / validation commands

- `cd backend && ./gradlew build check` (compile + ErrorProne/NullAway, Spotless, Checkstyle, tests, JaCoCo verification, Modulith `check`)
- `cd backend && ./gradlew spotlessCheck checkstyleMain` (Static stage subset)
- `pnpm --dir frontend lint && pnpm --dir frontend typecheck && pnpm --dir frontend build` (frontend Static + build)
- Block-then-pass: introduce a formatting violation → `spotlessCheck` fails; revert → passes
- `python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))"` (workflow YAML valid)
