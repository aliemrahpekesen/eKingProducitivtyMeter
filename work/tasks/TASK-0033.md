## Scope

Sprint Review Agent, Release Notes Agent, Delivery Risk Agent (the FR-083 Phase-3 minimum — **not**
all 18 canonical agents; `AgentArchitecture §5`'s remaining 14 stay Phase 4, out of this ADR
entirely) + Validation Agent v1, which gates publication of every one of these three agents' output —
no agent output ships without passing it, mirroring M6-A's `NumericCrossChecker` gate at a coarser,
per-report grain instead of per-number. Each agent runs as a job through TASK-0029's state machine,
executing inside `eip-workers` (TASK-0030) via the agent runtime (TASK-0031), citing sources found by
RAG (TASK-0032) with full LLM-call audit (FR-081, FR-087).

## Not in scope

The remaining 14 canonical agents (`AgentArchitecture §5`), MCP client/server, generated diagrams/
presentations, scheduling/notification channels beyond what TASK-0029's `report_schedule`/
`report_subscription` already provides — all Phase 4, out of this ADR.
