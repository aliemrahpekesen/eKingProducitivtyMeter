## Scope

`ObservabilityModel §3`'s exact rows: `eip_llm_calls_total{tenantId,provider,model,agent,outcome}`,
`eip_llm_tokens_total{tenantId,provider,model,direction}`, `eip_llm_cost_estimate{tenantId,provider,model}`,
`eip_llm_call_duration_seconds{provider,model}`, `eip_agent_runs_total{tenantId,agent,outcome}`.
Either extend M6-A's existing `eip.ai.calls{purpose,status}` counter to the full label set, or ship
both and document them as intentionally distinct (M6-A's stateless explain/narrate path vs. the
agent-runtime's per-agent-run path) — pick whichever the actual TASK-0033 call sites make cleaner;
the debt-register's own Target column already allows either resolution.

## Not in scope

Dashboards/alerts consuming these metrics (`ObservabilityModel §5/§6` territory, a follow-up once the
metrics exist) — this task ships the metrics themselves, correctly labeled and emitted.
