## Scope

pgvector-backed ([ADR-005](../../docs/adr/ADR-005-pgvector-default-vector-store.md) already the
default vector store); `ai.rag_document`/`rag_chunk`/`rag_chunk_embedding_*`/`rag_index_state`/
`rag_acl_grant`/`rag_retrieval_audit` (`DatabasePlan §2` already names these, no DDL yet).
Permission-aware retrieval per FR-095–101: retrieval must never surface a chunk the caller's
RBAC/tenant scope would not otherwise let them read directly — mirror the resource-level team-scope
pattern `TeamScopeFilter` already established for friction summaries, applied to retrieval results
before they ever reach a prompt.

## Not in scope

Any specific named agent consuming RAG output (TASK-0033); MCP server exposure of retrieval as an
external capability (Phase 4, out of this ADR).
