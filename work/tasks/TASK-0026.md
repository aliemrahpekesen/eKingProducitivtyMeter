## Scope

Closes:
- **DEBT-012 residual** — the `x-eip-permission` OpenAPI extension. Backend: a springdoc `OperationCustomizer` that emits `x-eip-permission` on every operation carrying `@RequiresPermission`, sourced from `Permission.wireId()` (never the enum name). Frontend: a minimal `<Can>` gate reading the caller's effective permissions (already delivered to the SPA via `GET /api/v1/session/auth`) so mutating admin controls are hidden/disabled when the permission is absent — matching the extension the backend now publishes.
- **DEBT-018 residual** — nested-JSON connector payloads. `RawRecord.payload` moves from a flat `Map<String,String>` to arbitrary nested JSON (`Map<String,Object>` / Jackson `JsonNode`), preserving the existing flat-map call sites additively and keeping the `jsonb` staging column (no migration — the column is already `jsonb`).
- **DEBT-013 residual** — relocate the compute/normalize JDBC orchestration still living in `eip-app` into its ADR-019-owning modules (`eip-ingestion` / `eip-analytics`); enforce with the existing `ApplicationModularityTests` + `ArchitectureRulesTest`.
- **DEBT-024** — the `audit.audit_event` write path (SecurityModel §11): an `AuditService` + `AuditEventRepository` in the owning module, per-tenant hash chaining (`hash = SHA-256(prevHash || canonical(record))`), the scheduled chain-verifier job (`eip_job_failures_total{job="audit-verify"}`), and retrofitting every already-logged security-relevant action (connector secret reveal, tenant/role mutations, service-token lifecycle) to also persist an audit row. New migration **V13**.

## Explicitly left open, with justification (not silently dropped)

- **DEBT-005 residual** — `infra/docker-compose/.env.example` CHANGE_ME convergence waits on an `eip-app`/`eip-migrate` Compose-container architecture decision that has not been requested. Building it means making that architecture call unilaterally.
- **DEBT-017 residual** — multi-stage `eip.raw.*`/`eip.canonical.*` Kafka topics. Volume-gated: the value only appears at 100k events/h, which needs the reference environment (G5-Evidence-SPRINT-01 §5). No behavioral gap at current scale.
- **DEBT-021 residual** + **DEBT-023** — both depend on the agent-runtime phase ADR-024 **deliberately defers** to later (LangChain4j adoption, job-runner/MinIO, per-agent metric breakdown). Building either now overrides a ratified ADR — the docs-first law forbids code silently diverging from an ADR decision.
