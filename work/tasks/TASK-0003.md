## Problem statement

Later sprints need a real local platform. Provide a one-command Docker Compose dev stack (`make dev-up`) that brings the required infrastructure — Postgres 16+pgvector, Redis 7, Kafka (KRaft), MinIO, Keycloak, OTel Collector, Prometheus, Grafana — to healthy within the NFR-050 budget, with healthchecks, dependency ordering, an `.env` contract, and printed local URLs. Backend and frontend run on the host in dev.

## Change class

CC-7 (infra tooling). No contract anchor, no schema, no application code. No real secrets (dev placeholders only, in a git-ignored `.env`).

## Acceptance criteria

1. `make dev-up` on a clean 16 GB host brings the core + observability profile to healthy in ≤ 15 min (NFR-050).
2. Every service passes its healthcheck; ports/bucket names match the canonical reference (8180 Keycloak HTTP, 3001 Grafana, `eip-artifacts`/`eip-ingest` buckets).
3. `make dev-down` stops and cleans the stack.
4. Smoke: services reachable on their endpoints; buckets present.

## Test plan / validation commands

- `docker compose -f infra/docker-compose/docker-compose.yml --profile core --profile observability config -q`
- `make dev-up` → `docker compose … ps` (all healthy) → `make dev-down`
- Verify buckets created (`minio-init` logs) and Keycloak realm discovery reachable
