**Deviations / deferrals** (documented, no DEBT required — all are correct task-boundary scoping):
1. Gradle build root lives under `/backend` (RepositoryStructure §2), not repo root as the TaskSpecs file-list simplified — AC-3 binds to RepositoryStructure (docs-first).
2. Static-analysis enforcement (Error Prone, NullAway, Checkstyle, ArchUnit) is present as buildSrc convention hooks but its G1 wiring is TASK-0002's lane (CI static stage); Spotless is wired now (it validates the license headers this task adds).
3. The Spring Modulith `ModularityTests` harness is deferred to TASK-0005 (eip-core, CC-1), which owns the module-boundary test; `eip.modulith-conventions` exists as the hook.
4. `eip-workers` is a plain library skeleton (no boot main / boot-app-conventions yet) — its worker main lands in Phase 1 (SPRINT-05); applying boot now would break `bootJar` (no mainClass). Task scope limited the app-class stub to `eip-app`.
5. Local Gradle runtime: this box defaults to Java 25, which Gradle 8.14.3 rejects as its own JVM; `gradle/gradle-daemon-jvm.properties` pins the daemon to Java 21 so `./gradlew build` runs portably regardless of the launcher's default JVM (CI on Java 21 needs no override).
