## Problem statement

Build a React 18 + TypeScript (strict) + Vite + TanStack Query SPA that renders three screens over the existing `/api/v1` read surface — session, connectors, Engineering Friction — consuming the committed OpenAPI contract as the source of truth. No new backend endpoints, no real connectors, no AI, no OIDC.

## Architecture constraints honored

- **Contract is the source of truth.** `src/api/types.ts` mirrors `backend/eip-app/openapi/eip-openapi-v1.json` field-for-field; **no field the contract does not define is invented** (e.g. `ConnectorView` has no last-sync/checkpoint, so no such column is shown). The CI-generated client is deferred → [DEBT-016](../debt-register.md).
- **Server state in TanStack Query only** (`useSession`, `useConnectors` via `useInfiniteQuery` cursor pagination, `useFrictionSummary`); loading / error / empty states everywhere.
- **Honest demo framing** (NFR-071 / anti-surveillance): a persistent `DemoBanner` states the data is seeded simulation; each `simulation = true` connector gets a `SIMULATION` badge; the friction card surfaces the metric's caveats + gaming-risks (FEAT-031) and shows team-level data only — no individual developers.
- **No auth beyond the dev surface:** the tenant id is entered in a dev `TenantBar` and sent as `X-EIP-Tenant` (mirrors the backend dev resolver; OIDC replaces it in SPRINT-02). The Vite dev server proxies `/api` + `/v3` to eip-app.
- **Quality wired:** Prettier (closes [DEBT-004](../debt-register.md)), ESLint, TS strict, Vitest, Vite build — all in the `frontend` CI job.

## Acceptance criteria

1. Session view renders the current tenant id + organization + Active status from `GET /api/v1/session` [screen 1].
2. Connector list renders type/name/status + a simulation indicator from the cursor-paginated `GET /api/v1/connectors`, with a working "Load more" [screen 2].
3. Engineering Friction card renders the worst-first headline score + per-team breakdown + the metric definition/caveats/gaming-risks from `GET /api/v1/friction/summary` [screen 3].
4. A visible demo/simulation indicator appears wherever seeded data is shown.
5. Loading / error (problem+json incl. traceId) / empty states for each screen.
6. `pnpm install --frozen-lockfile`, `format:check`, `lint`, `typecheck`, `test`, `build` all green; `./gradlew check` unchanged/green.
