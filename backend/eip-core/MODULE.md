# Module: eip-core

- **Root package:** `com.eip.core`
- **Owner:** R-BA (contract anchor — CC-1; R-CA co-owns)
- **Allowed dependencies:** (none — leaf). Third-party: JSpecify annotations only (runtime); JUnit 5 / AssertJ / ArchUnit / Spring Modulith (test).
- **State:** Phase-0 shared-kernel base types (TASK-0005, P0-E2-S1). Types only — no persistence, no Kafka, no SPI implementations, no business logic.

## Purpose

Shared kernel: the canonical base types every downstream module depends on — the `WorkItem` type discriminator, canonical entity names, `ExternalRef` provenance, the domain-event envelope, and the UUIDv7 identity convention — plus the error taxonomy root and the SPI package roots. Per [DomainModel §1–§2](../../docs/architecture/DomainModel.md) and [BackendPlan §1](../../docs/engineering/BackendPlan.md).

| `com.eip.core.domain` | `WorkItemType` (enum `EPIC\|FEATURE\|STORY\|TASK\|BUG\|INCIDENT_TICKET`); `EntityType` (canonical entity names); `ExternalRef` (record — immutable `externalId` vs mutable `externalKey` + `keyAliases`, AD-14); `UuidV7Generator` (interface) + `DefaultUuidV7Generator` (`Clock`-injected, RFC 9562 v7) |

## Invariants

- **Leaf forever (AP-1).** Zero dependency on any other `eip-*` module. Enforced by Gradle module isolation (no project dependency → other modules are not on the classpath — a cross-module import is a compile-red event), the Spring Modulith `ApplicationModules.of("com.eip.core").verify()` test, and the ArchUnit `LeafBoundaryTest` ([BackendPlan §1](../../docs/engineering/BackendPlan.md)).
- **Tenant-scoped by construction (AP-2).** `ExternalRef` and `EventEnvelope` both carry `tenantId`; no type here can produce an individual-ranking or activity-count metric (AP-8 / NFR-071).
- **Identity (AD-14).** `externalId` is immutable and the only identity key; `externalKey` is mutable/display-only and its prior values live in `keyAliases`.
- **Conventions.** Value objects are `record`s; closed sets are `enum`s; the exception taxonomy is `sealed`; time is `java.time.Instant` (UTC by construction — `Date`/`LocalDateTime` forbidden); ids are UUIDv7 from `UuidV7Generator`; `@NullMarked` at every package ([CodingStandards §2](../../engineering-operating-system/CodingStandards.md)).
- Package-by-module: all code sits under `com.eip.core.<area>` ([CodingStandards §2.3](../../engineering-operating-system/CodingStandards.md)).
